# Présentation du projet

Projet de 3 semaines, d'un site e-commerce, où nous réaliserons la boutique d'une entreprise de vente 
de gâteau à des formats assez atypiques et originaux d'éléments normalement répréhensibles mais sous forme de
pâtisserie trompe l'oeil, dans un style général à le darknet qui rend cohérent le thème des ventes du site 
Pour respecter le contexte de l'entreprise.
